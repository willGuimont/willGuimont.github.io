Revduino is an Arduino library for non-CAN REV Robotics devices. It currently supports the Color Sensor V3 over I²C, with raw RGB, infrared, and proximity readings, measurement configuration, and status reporting.

The library is available through the [PlatformIO Registry](https://registry.platformio.org/libraries/willguimont/Revduino) and includes examples for Arduino Uno and Mega. For CAN-based motor controllers, see [CanControl](@/projects/cancontrol/index.md).
