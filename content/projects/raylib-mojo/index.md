`raylib_mojo` provides Mojo bindings for [raylib](https://www.raylib.com/) and [raygui](https://github.com/raysan5/raygui), making it possible to build games, graphical applications, and interactive GPU demos in Mojo.

The project includes automatically generated bindings, Pixi-managed native dependencies, and examples covering 2D and 3D graphics, audio, GUI controls, animation, and GPU compute kernels. It can be added to a Mojo project through [mojoshelf](https://mojoshelf.org/tins/raylib_mojo) or as a Git submodule.
