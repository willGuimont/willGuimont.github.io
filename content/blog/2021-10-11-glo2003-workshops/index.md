I worked on these exercises and teaching resources for **GLO-2003 — Introduction aux processus du génie logiciel**, at Université Laval. They give students practical experience with testing, test-driven development, Clean Code, and refactoring.

- [String Calculator TDD Kata](https://github.com/glo2003/Exercice-TDD-string-calculator): a small string-calculator exercise for practising test-driven development. The focus is on building functionality incrementally through the test, implement, and refactor cycle.
- [UTournament](https://github.com/glo2003/UTournament): a Java API for managing tournaments, used to explore software testing. It provides examples of unit, integration, system, and acceptance tests so students can compare their scope and purpose.
- [Clean Code and Refactoring — Short Version](https://github.com/glo2003/Exercice-CleanCode-Refactoring-Court): a short exercise for practising code readability and refactoring while preserving behaviour.
- [Clean Code and Refactoring — Long Version](https://github.com/glo2003/Exercice-CleanCode-Refactoring-Longue): a longer version of the exercise, with more room to practise improving the structure and clarity of existing code.

The goal is to make these practices concrete: write tests, read existing code, and improve it in small steps.

For accompanying slides on software testing with UTournament, see [Les tests en pratique](@/blog/2022-03-14-tests-en-pratique/index.md).
